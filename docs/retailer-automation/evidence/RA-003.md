tests prove it is not referenced by `app/` or `.github/workflows/`.

The completeness test reads current JavaScript output fields, snapshot enums
and control/review SQL constraints. A new status in the inventoried active
emitters fails unless the matrix classifies it. During implementation this test
found the nested idempotency status `DEFERRED`; it was added as
`CONTEXT_REQUIRED` rather than silently treated as success or failure.
